# Universal 下载区设计

## 目标

将下载区现有的三个架构卡片（arm64-v8a、armeabi-v7a、x86_64）合并为一个名为 `Universal` 的下载卡片，并让卡片在下载区内水平居中。

## 设计

- 删除三个架构专属卡片，只保留一个下载卡片。
- 卡片标题显示 `Universal`。
- 卡片说明使用“全架构通用包”，避免继续展示特定架构的推荐、旧设备或模拟器提示。
- 保留现有下载图标、按钮样式、悬浮反馈和下载区整体视觉语言。
- 下载容器使用单列、适中最大宽度并水平居中，移动端继续保持自适应。
- 暂时沿用现有可下载链接作为占位；最终 Universal 地址由用户后续替换。

## 范围

只修改下载区相关 CSS 与 HTML，不改动导航、其他页面区块、版本信息或外部资源。

## 验证

- 页面源码中只出现一个下载卡片，且显示 `Universal`。
- 下载容器具有单列居中布局。
- HTML 结构无明显未闭合标签，现有下载区元信息仍保留。
